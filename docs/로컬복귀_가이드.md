## 2. 원인 (확정)

세 가지가 겹쳤습니다. 순서대로 결정적입니다.

### 2-1. Agent Teams 기능이 클라우드 세션에서 꺼져 있음

"팀"은 별명이 아니라 Claude Code 의 **Agent Teams** 기능입니다. 이 기능은 기본값이 **비활성**입니다.

공식 문서:

> Agent teams are disabled by default. Enable them by setting `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`.
> Without that variable, **no team is set up at session start, no team directories are written,
> and Claude does not spawn or propose teammates.**

클라우드 세션에서 직접 확인한 값:

```
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS = []      (비어 있음)
~/.claude/teams/                        없음
~/.claude/tasks/                        없음
```

즉 현재 환경에서는 팀이 숨겨진 것이 아니라 **팀이라는 개념 자체가 작동하지 않습니다.**

### 2-2. 팀은 원래 세션을 넘어 살아남지 못함

| 문서상 사실 | 의미 |
|---|---|
| `One team per session` — 세션 1개에 팀 1개, 세션 간 공유 불가 | 새 세션에서 옛 팀을 부를 수 없음 |
| 팀 이름은 `session-` + 세션 ID 앞 8자 로 자동 생성 | 사람이 이름을 고정할 수 없음 |
| 팀 설정 디렉터리는 **세션 종료 시 삭제** | 팀 자체는 소멸이 정상 동작 |
| 작업 목록은 **로컬에만 남고 절대 업로드되지 않음** | 클라우드로 옮겨올 방법이 원천적으로 없음 |
| `/resume` 와 `/rewind` 로 팀원이 복원되지 않음 | 되살리기 불가 |

**따라서 벼리팀·앱성팀의 소실은 고장이 아니라 설계상 예정된 동작입니다.**
깃허브 전환은 이 사실을 드러낸 계기였습니다.

### 2-3. 저장소에 아무것도 커밋되어 있지 않았음

깃허브 전환 이후 세션은 매번 새 컨테이너에 `silro742/BIM` 저장소만 복제합니다.
커밋되지 않은 것은 존재하지 않습니다. 그런데 전환 시점의 저장소 내용은:

깃허브 전환은 로컬 파일을 지우지 않습니다. PC 에 다음이 남아 있을 가능성이 높습니다.

| `%USERPROFILE%\.claude\teams\` | 팀 런타임 설정 | 삭제됨 |
| `%USERPROFILE%\Desktop\토성\` | 앱 작업물 (Node 06, 07 등) | 보존 |

## 4. 실행 절차

### 1단계 — 진단 (읽기 전용)

`tools\01_진단_벼리팀찾기.ps1` 을 PC 에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\01_진단_벼리팀찾기.ps1
```

위 5개 경로를 전수 조사해 바탕화면에 `벼리팀_진단결과_날짜.txt` 를 남깁니다.
**파일을 수정하거나 삭제하지 않습니다.**

### 2단계 — 로컬 복귀 설치

`tools\02_로컬복귀_설치.ps1` 을 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\02_로컬복귀_설치.ps1
```

- Claude Code 설치 여부 확인, 없으면 공식 스크립트로 설치
- `~\.claude\settings.json` 을 **백업한 뒤** 팀 플래그만 병합 (기존 설정 보존)
- 설치 상태 검증

### 3단계 — 사용

```powershell
cd "$env:USERPROFILE\Desktop\토성"
claude
```

이제 토성 폴더 전체를 직접 읽고 씁니다. 깃허브를 거치지 않습니다.

팀을 만들 때:

```
팀원 3명을 띄워서 06 표준횡단 앱을 각각 다른 관점으로 검토해줘
```

휴대폰·웹에서 진행 상황을 함께 보려면 세션 안에서 `/remote-control` 을 실행합니다.
로컬에서 실행되면서(= 파일 전체 접근) 원격 모니터링만 얹는 방식입니다.

### 4단계 — 역할을 영구 보존

팀 자체는 매번 사라지지만 **역할 정의는 파일로 남습니다.**
`.claude/agents/` 에 정의를 두면 언제든 같은 역할의 팀원을 재소환할 수 있고,
저장소에 커밋되므로 로컬이든 클라우드든 따라옵니다.

작성 규칙은 `.claude/agents/README.md`, 서식은 `.claude/agents/_템플릿.md` 참고.
