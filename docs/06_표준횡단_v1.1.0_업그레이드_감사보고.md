## 2. 부적용 판정 (근거)

- **AHP + 3D RRT-star 노선 최적화 (§2.4)** — 노선 선정은 상류(선형 설계) 노드 소관. 본 앱(Node 06)은 확정 선형의 횡단·토공 담당.
- **TCS-Net 딥러닝 점군 분할 (§2.7)** — 점군 입력이 없는 앱. 허위 기능 표방 금지.
- **Leapfrog 지질모델 연동 (§2.5)** — 시추공 데이터 스키마 부재. 단, 그 취지(지층별 변화율 차등)는 항목 1로 흡수.
- **InfoDrainage 실시간 배수 해석 (§2.1)** — 배수는 하류 별도 노드.

## 3. 검증 (헤드리스 Chromium 실측)

- 7개 스크립트 블록 구문검사 전건 통과, 페이지 런타임 오류 0건.
- 합성좌표 51측점: 배지 `좌표: 합성(Synthesized) ⚠`, R05 FAIL, 핸드오프 `coord.synthetic=true`.
- 실좌표 3측점 핸드오프 적재: R05 PASS, 배지 녹색 전환.
- 곡선반경 120 m + 양단면법: R06 FAIL(호길이차>5% 2개소 적발, 각주공식 전환 요구).
- 토사 구간 절토 17,324 m³ → 운반 21,655 m³(×1.25), 유용토 15,591.6 m³(×0.90) — L/C 매핑 정확.
- 주입 모듈(deliberation-std/v1, handoff-contract-std/v2, decision-v1)은 「직접 편집 금지」 규약에 따라 무수정 보존.
