2. **동일 계열 앱의 실제 구조** — 본 저장소 `BIM_Slope_EL_Automation.html`(962행, 단일 파일)의 패턴:
   - `const steps=[...]` 기반 좌측 워크플로우 내비게이션
   - `<canvas>` 2D 뷰 + 우측 패널(`renderPanel()`)의 2열 레이아웃
   - `const REGULATIONS=[...]` + `checkCompliance()` 법규 게이트
   - `const SCRIPT_TEMPLATES={dynamo, revit_csharp, civil3d_python, civil3d_csharp}` 스크립트 생성기 + `downloadScript()`
   - 전역 상태 변수 + `renderContent()` 단방향 재렌더링, 외부 의존성 0(오프라인 구동)

→ 실제 소스 확인 후 §4의 함수 배치(구현 위치)만 재매핑하면 되며, 기능 명세·수용기준·데이터 스키마는 그대로 유효하다.

## 2. 업그레이드 목표 및 설계 원칙

### 2.1 목표 (Objectives)
- **O1. 무결성 우선(Integrity First)** — 좌표·타겟·체적 3대 오염원을 앱이 *차단*한다. 경고가 아니라 게이트다.
- **O2. 물량 신뢰도(Quantity Confidence)** — 기하 체적 → 시공 체적(토량변화율 반영, 운반 계획 연동)으로 격상.
- **O3. 파이프라인 연속성(SSOT)** — 상·하류 데이터가 JSON/LandXML/IFC 4.3 표준 스키마로만 유동.
- **O4. 반복 작업 제거(Automation)** — 구조물 구간 타겟 스위칭·지형 분할·LOD 제어를 스크립트로 자동 생성.
- **O5. 견고성(Robustness)** — 한글 경로·공백 경로·콜드스타트에서도 실패하지 않는다.

### 2.2 설계 원칙 (Principles)
1. **단일 파일 유지** — 외부 CDN·빌드 도구 없이 오프라인 더블클릭 구동을 유지한다(현장 보안망 대응).
2. **게이트는 하드 블록** — P0 위반 시 하류 내보내기 버튼(`downloadScript`, `exportJSON`)을 `disabled` 처리.
3. **계수는 하드코딩 금지** — L/C값, 사면 구배, 최소 횡단경사 등 모든 기준값은 편집 가능한 `PARAMS` 객체 + 프로젝트 JSON 오버라이드.
4. **모든 산출값에 출처 표기** — 각 결과 카드에 산출 기법(`AEA` / `Prismoidal` / `Composite TIN`)과 신뢰도 배지 부착.
5. **스키마 버저닝** — 모든 입출력 JSON에 `schema_version` 필드. 하위 호환 파서 유지.

### F-01 [P0] 좌표계 무결성 게이트 (Coordinate Integrity Gate)
> 근거: 연구자료 §4 "가장 대표적이고 파괴적인 오류는 좌표 합성 왜곡"

**요구사항**
1. 상류 JSON 로드 시 `project.crs.epsg` 존재 여부를 최우선 검사.
2. EPSG 화이트리스트 대조: 5186(중부), 5185(서부), 5187(동부), 5188(동해), 5179(UTM-K). 목록 외 값은 **경고 + 수동 확인 체크박스**로만 통과.
3. **합성좌표 탐지 휴리스틱** — 다음 중 하나라도 참이면 `SYNTHESIZED` 판정:
   - `northing`/`easting` 필드 자체가 결측
   - 모든 측점의 좌표가 완전 직선상에 정렬(잔차 RMS < 1e-6 m)인데 선형에 `arc`/`clothoid` 요소가 존재 ← **가장 결정적인 지표**
   - 좌표 절대값이 한국 투영 좌표 유효 범위(N: 100,000–800,000 / E: 0–400,000) 이탈
   - 원점이 (0,0) 근방(±1,000 m)
4. 판정 시 결과: 상단 **적색 배너 + 하류 내보내기 전면 차단**, 측점 테이블 비고란에 `좌표합성(Synthesized)` 태그, 상류 재발행 요청문(복사 가능한 텍스트) 자동 생성.

**구현 스케치**
```js
const KR_EPSG = {5186:"중부원점(Central)",5185:"서부",5187:"동부",5188:"동해",5179:"UTM-K"};

function detectSynthesizedCRS(data){
  const f=[], secs=data.sections||[];
  if(!data.project?.crs?.epsg) f.push("EPSG 코드 미기재");
  const hasCurve=(data.alignment?.elements||[]).some(e=>e.type!=="line");
  const pts=secs.filter(s=>Number.isFinite(s.northing)&&Number.isFinite(s.easting));
  if(pts.length<secs.length) f.push("측점 실좌표 결측");
  if(pts.length>=3){
    // 최소제곱 직선 적합 잔차
    const n=pts.length,
          mx=pts.reduce((a,p)=>a+p.easting,0)/n, my=pts.reduce((a,p)=>a+p.northing,0)/n;
    let sxx=0,sxy=0; pts.forEach(p=>{sxx+=(p.easting-mx)**2; sxy+=(p.easting-mx)*(p.northing-my);});
    const k=sxx?sxy/sxx:0;
    const rms=Math.sqrt(pts.reduce((a,p)=>a+((p.northing-my)-k*(p.easting-mx))**2,0)/n);
    if(hasCurve && rms<1e-6) f.push("곡선 선형인데 좌표가 완전 직선 → 합성좌표 강력 의심");
    const out=pts.some(p=>p.northing<1e5||p.northing>8e5||p.easting<0||p.easting>4e5);
    if(out) f.push("좌표가 국내 투영 유효범위 이탈");
    if(Math.abs(mx)<1000&&Math.abs(my)<1000) f.push("원점 (0,0) 근방 — 상대좌표 의심");
  }
  return {synthesized:f.length>0, reasons:f};
}
```

**수용기준(AC)**
- AC-1: 곡선 포함 + 좌표 결측 샘플 투입 시 내보내기 버튼이 `disabled` 이며 사유 3건 이상이 표시된다.
- AC-2: EPSG:5186 + 실좌표 정상 샘플은 게이트를 무경고 통과한다.
- AC-3: 게이트 판정 결과가 출력 JSON `gates.blocking` 에 기록된다.

### F-02 [P0] 체적 산출 3중 엔진 및 복합토량 강제
> 근거: 연구자료 §3 및 체적 산출 기법 비교표

**요구사항**
1. 세 가지 기법을 모두 계산하고 **나란히 비교 표시**한다.
   - 양단면평균법 `V = (A1+A2)/2 × L`
   - 정밀법(Prismoidal) `V = L/6 × (A1 + 4Am + A2)`
   - 복합토량(Composite TIN) `V = Σ(삼각형 면적 × 평균 절·성 깊이)`
2. **곡선부 편심 보정(Curvature Correction, Pappus 정리)** — 반경 R 구간에서 단면 도심이 곡률 중심 반대쪽으로 e만큼 치우친 경우 `V' = V × (1 + e/R)`(곡률 중심 쪽이면 `1 − e/R`). 편측 확폭·편경사 구간에서 필수.
3. **불일치 경보** — `|AEA − CompositeTIN| / CompositeTIN > 3%` 이면 황색, `> 7%` 이면 적색 경보 + 해당 측점 구간 하이라이트. 자료가 지적한 "수만 ㎥ 오차" 사고를 사전 포착.
4. **하류 전달값은 Composite TIN 만 허용**. AEA 선택 시 내보내기 차단(P0 게이트 `G-02-METHOD`).

**구현 스케치**
```js
function volAEA(a1,a2,L){ return (a1+a2)/2*L; }
function volPrismoidal(a1,am,a2,L){ return L/6*(a1+4*am+a2); }
function curvatureFactor(e,R,towardCenter){ return R? (1+(towardCenter?-1:1)*e/R) : 1; }

// 복합토량: EG TIN과 DG TIN의 수직 프리즘 적분
function volCompositeTIN(tris, egZ, dgZ){
  let cut=0, fill=0;
  for(const t of tris){
    const A=triArea2D(t);
    const d=t.v.map(i=>dgZ[i]-egZ[i]);            // + = 성토, − = 절토
    const dm=(d[0]+d[1]+d[2])/3;
    if(d.every(x=>x>=0))      fill+=A*dm;
    else if(d.every(x=>x<=0)) cut +=A*-dm;
    else { const s=subdivideZeroCrossing(t,d);    // 영단면 교선 분할
           cut+=s.cut; fill+=s.fill; }
  }
  return {cut_m3:cut, fill_m3:fill};
}
```
> 영단면 교차 삼각형은 반드시 세분(subdivide)해야 한다. 단순 평균 깊이 사용 시 절·성 혼재 구간에서 상쇄 오차가 발생한다.

**AC**
- AC-1: 직선 구간 샘플에서 3기법 편차 < 1%.
- AC-2: R=60 m 급곡선 + 편측 확폭 샘플에서 AEA 대비 Composite TIN 차이가 정량 표기되고 적색 경보가 뜬다.
- AC-3: 곡률 보정 on/off 결과가 각각 표기된다.

### F-03 [P0] 코리더 타겟·리빌드 신선도 검사
> 근거: 연구자료 §4 "코리더 타겟 단절 및 형상 자동 업데이트 누락"

**요구사항**
1. `alignment.geometry_hash` 와 `corridor.last_rebuild` 시각을 비교 — 선형 해시가 바뀐 뒤 리빌드가 없으면 **`STALE` 판정 → 차단**.
2. `corridor.auto_rebuild === false` 이면 황색 경고("성능 목적 자동 재구성 해제 상태에서 성과품 추출 시도").
3. 측점별 `target_status.broken === true` 또는 `daylight` 가 `none` 인 구간을 목록화하고 캔버스 상에 적색 마커 표시.
4. 사면(Daylight) 미도달 구간 — 절·성 사면이 지정 최대 연장 내에 원지반과 만나지 못한 측점을 별도 분류(옹벽 검토 대상 후보로 하류 전달).

**AC**: 리빌드 시각 < 선형 변경 시각인 샘플에서 내보내기 차단 + "코리더 재구성 필요" 사유 표기.

### F-04 [P1] 토량변화율(L/C) 지층별 동적 매핑 + 누가토량곡선
> 근거: 연구자료 §3 "토량 변화율의 동적 반영 부재"

**요구사항**
1. 지층 분류별 기본 계수 테이블(편집 가능, 프로젝트 JSON 오버라이드 필수 안내).

| 토질 구분 | L(팽창률, 흐트러진/자연) | C(다짐률, 다짐/자연) | 비고 |
|---|---|---|---|
| 토사(Common soil) | 1.20 – 1.30 | 0.87 – 0.90 | 함수비 영향 큼 |
| 리핑암(Ripping rock) | 1.30 – 1.40 | 1.00 – 1.05 | |
| 발파암(Blasting rock) | 1.50 – 1.60 | 1.15 – 1.20 | 유용 시 입도 관리 |
| 폐석회 등 특수토 | 프로젝트 정의 | 프로젝트 정의 | 건조시간 별도 §F-11 |

> ⚠️ 위 값은 **설계 착수용 기본값**이다. 반드시 프로젝트 토질조사 보고서 값으로 대체하도록 UI에 고지하고, 미대체 시 산출 결과에 "기본계수 사용" 배지를 부착한다.

2. 계산 규칙 — 토량 균형은 **자연상태(Bank) 기준**으로 통일.
   - 성토에 필요한 자연토량 `V_bank_needed = V_compacted / C`
   - 운반 토량(흐트러진 상태) `V_loose = V_bank × L`
3. **누가토량곡선(Mass Haul Diagram)** 신설 — x축 측점, y축 누가 토량. 유용 구간·토취장(Borrow)·사토장(Waste) 구간을 색으로 구분하고, 평균 운반거리(Average Haul Distance)와 무상 운반거리(Free Haul) 초과분을 산출.
4. 지층별 서로 다른 계수를 자동 매핑(연구자료가 지적한 "지질 DB ↔ 코리더 연동 스크립트"의 앱 내 구현).

**AC**: 발파암 40% 포함 샘플에서 순수 기하 체적 대비 사토량 차이가 정량 표기되고, 사토장 소요 용량이 ㎥로 제시된다.

### F-05 [P1] 구조물 구간(B/T) 코리더 타겟 자동 스위칭 스크립트 생성
> 근거: 연구자료 §5.2

**요구사항**
1. `stype` 이 `B`(교량)/`T`(터널)인 측점 구간을 자동 검출하고, 토공↔구조물 **트랜지션 구간**(기본 전후 20 m, 조정 가능)을 식별.
2. 해당 구간에 대해 Civil 3D용 Dynamo 스크립트를 생성 — 사면 타겟을 원지반 표면에서 **교대 벽면/갱구부 형상선(Feature Line)** 으로 전환.
3. 생성 스크립트에는 ① 대상 측점 범위 ② 타겟 종류(Surface→FeatureLine) ③ 실패 시 롤백 로그가 포함된다.

**템플릿 스케치(Dynamo Python)**
```python
# Corridor Target Switching @ Structure Zones  (Node 06 auto-generated)
# stype B/T ranges: {{RANGES}}
for rng in STRUCTURE_RANGES:
    region = corridor.GetBaselineRegionByStation(rng["sta_in"], rng["sta_out"])
    for sub in region.AppliedAssemblySubassemblies:
        if sub.Name in DAYLIGHT_SUBS:
            sub.SetTargetSurface(None)                      # 원지반 타겟 해제
            sub.SetTargetFeatureLine(rng["feature_line_id"]) # 구조물 벽면으로 전환
corridor.Rebuild()
```

**AC**: B/T 구간 3개가 포함된 샘플에서 구간 범위와 전환 대상이 정확히 나열된 스크립트가 다운로드된다.

### F-07 [P1] 견고성 강화 — 인코딩·경로·브리지 프로토콜
> 근거: 연구자료 §4 "인코딩 파손 및 네트워크 프로토콜 위반"

**요구사항**
1. **인코딩** — 생성 스크립트 전량 UTF-8. Python은 `# -*- coding: utf-8 -*-`, BAT는 `chcp 65001 > nul`, 저널·LISP는 비ASCII 문자열을 유니코드 이스케이프로 치환(`toUnicodeEscape()` 유틸 신설).
2. **경로** — 모든 경로를 큰따옴표 인용, 역슬래시 정규화, 공백·한글 포함 시 자동 검사 경고. 경로 유효성 프리플라이트 체크리스트 표기.
3. **브리지** — 로컬 HTTP 요청에 **지수 백오프 재시도**(0.5s→1s→2s→4s, 최대 5회) + 헬스체크 엔드포인트 선행 호출로 콜드스타트 대응. 실패 시 사용자에게 "스크립트 수동 실행" 폴백 경로 제시.

```js
async function bridgeFetch(url,opt={},max=5){
  for(let i=0;i<max;i++){
    try{ const r=await fetch(url,{...opt,cache:"no-store"}); if(r.ok) return r; }
    catch(e){ /* connection refused → 재시도 */ }
    await new Promise(s=>setTimeout(s,500*2**i));
  }
  throw new Error("로컬 브리지 연결 실패 — 생성된 스크립트를 수동 실행하세요.");
}
```

**AC**: 서버 미기동 상태에서 앱이 멈추지 않고 5회 재시도 후 수동 실행 안내로 전환된다.

| `landxml_ifc` | 내보내기 | XML/IFC | **신규** | LandXML·IFC 4.3 매핑 산출 |
| `lisp_batch` | AutoCAD LISP + BAT | LISP/BAT | 개선 | UTF-8·경로 인용·재시도 내장 |

모든 템플릿 공통 헤더에 `schema_version`, 생성 시각, 게이트 통과 여부를 주석으로 각인하여 **차단 상태에서 생성된 스크립트가 현장에서 오용되는 것을 방지**한다.
