ESRI ASCII Grid (.asc) 를 올리면 합성 지형 데모가 실측 지형으로 바뀌고 수렴점이 실좌표 집수정 후보가 됩니다. 격자 크기·셀 크기·원점을 파일 헤더에서 직접 읽으므로 아래 칸에 손으로 넣던 원점 이중 관리가 사라집니다. NODATA 셀은 통과 불가로 처리합니다.
QGIS 4.0 절차: 래스터 레이어 선택 → [래스터 → 변환 → 포맷 변환] → 출력 형식 AAIGrid → 사업 좌표계(EPSG:5186 등)로 저장. 좌표계 정보는 .asc 에 담기지 않으므로 앱 EPSG 설정과 같은 좌표계로 내보내야 합니다.

    🧮 계산식 요약
    
    
    [집중시간] Kirpich
  Tc = 0.0195 × L^0.77 × S^(-0.385)          L(m), S(무차원), Tc(분)

[강우강도] Talbot
  i  = a / (Tc + b)                           i(mm/hr), a·b는 지역 IDF 회귀값

[설계유량] 합리식
  Q  = C × i × A / 360                        A(ha), Q(m³/s)

[만관 통수능] Manning
  Q_full = (1/n) · A · R^(2/3) · S^(1/2)
  A = πD²/4 ,  R = D/4                        n: 관종 프리셋(PIPE_MATERIALS) 콘크리트 0.013 / HDPE·PVC 0.011 / 덕타일 0.012 (전 항목 미검증·재정의 가능)

[부분흐름] 원형관 중심각 θ 이분법 (90회)
  A = D²/8 · (θ − sinθ)      P = Dθ/2      R = A/P
  h = D/2 · (1 − cos(θ/2))                    최대 통수능은 θ ≈ 5.278 rad

[부분흐름 · 퇴적 보정] h_sed 입력 시 (P2-1)
  A = A_원(h) − A_원(h_sed)                   퇴적면 위 ~ 수면
  P = (호길이(h) − 호길이(h_sed)) + 현폭(h_sed)  ← 퇴적면도 마찰면
  h_sed = 0 이면 위 청관식과 완전히 동일 (회귀 앵커)

[유출계수 가중평균] (P1-1)
  C_w = Σ(Cᵢ·Aᵢ) / ΣAᵢ                        Aᵢ 합이 유역 A 와 ±5% 이내여야 함

[충전율] (P2-3)
  fill = Q_설계 / Q_full                       ≥1 이면 과부하 → 하류 경로 전파 표시

[물량 개산] (P3-3)
  W = OD + 2b   H = 평균심도 + e   Vc = W·H·L   (수직 터파기 가정)
  Vf = max(0, Vc − π·OD²/4·L − W·e·L)

[피복]
  cover = 지표고 − (관저고 + 내경 + 관벽두께)   ← 관 상단 외측 기준

[3D 표면간 이격]
  sep = √(평면최근접거리² + 축표고차²) − (관로외반경 + 지장물외반경)
  sep < 0 → 하드 클래시 / 0 ≤ sep < 필요이격 → 소프트 클래시

[SUDS 저류]
  V_total = C × (P/1000) × A×10000            P(mm), A(ha)
  V_저류  = V_total × 저류목표율

    하수도시설기준(2011)은 구판입니다. 현행은 KDS 61 00 00 : 2022 하수도설계기준 — 관로시설 1.3(유속·경사), 2.3(최소관경).
